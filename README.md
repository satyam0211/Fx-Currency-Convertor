# FXConvert — Currency Converter

A modern, glassmorphism-style currency converter that fetches live foreign exchange rates.

## Features
- **Live Rates**: Dynamic exchange rates via `open.er-api.com`.
- **Easy Swap**: Reverse conversion direction with one click.
- **Glassmorphic UI**: Beautiful gradients and smooth animations.
- **Responsive Design**: Adapts seamlessly to mobile and desktop screens.

## Quick Start
Open `index.html` in any web browser to run the application locally.

## Project Structure
- `index.html` — App structure and markup
- `style.css` — Custom styling and animations
- `script.js` — Core logic and API integration
